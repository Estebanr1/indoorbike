BIKE RACE

Guía de Conexión — NodeMCU + Sensor HW-511
01
CONECTAR EL HARDWARE
Sensor HW-511 → NodeMCU ESP8266
NodeMCU       HW-511
──────────     ──────
3.3V    ──────► VCC (cable rojo)
GND    ──────► GND (cable negro)
D2     ──────► OUT (cable verde)
⚠️ Usar 3.3V — NO conectar a 5V, puede dañar el NodeMCU permanentemente.
💡 El sensor tiene un potenciómetro azul para ajustar sensibilidad. Girarlo con destornillador fino si no detecta bien.
02
INSTALAR LIBRERÍAS
Arduino IDE → Herramientas → Gestionar Librerías
WiFiManager
por tzapu
v2.0.17 o superior
WebSockets
por Markus Sattler
v2.4.1 o superior
ArduinoJson
por Benoit Blanchon
v6.x
💡 En el buscador escribí el nombre exacto, seleccioná la librería correcta por autor y presioná Instalar.
03
SUBIR EL CÓDIGO
Una sola vez por NodeMCU
  • Abrí el Arduino IDE
  • Herramientas → Placa → NodeMCU 1.0 (ESP-12E Module)
  • Herramientas → Puerto → seleccioná el COM del NodeMCU
  • Herramientas → Velocidad de subida → 115200
  • Abrí el archivo nodemcu-sensor-hw511.ino incluido en el proyecto
  • Presioná el botón Subir → y esperá que termine
  • El LED del NodeMCU va a parpadear 2 veces cuando esté listo
✓ Una vez subido el código, no necesitás volver a hacerlo. El firmware queda guardado en el NodeMCU permanentemente.
04
CONFIGURAR WIFI
Solo la primera vez — queda guardado para siempre
El NodeMCU arranca sin WiFi configurado y crea su propio punto de acceso para que le pases las credenciales.
  • Conectá el NodeMCU por USB a cualquier cargador o PC (solo para alimentación)
  • Desde tu celu o PC, buscá la red WiFi:
RED WIFI
BikeGame-Setup
Contraseña: bikerace123
  • Conectate a esa red desde tu dispositivo
  • Abrí el navegador y entrá a 192.168.4.1
  • Aparece un formulario — ingresá el nombre y contraseña de tu WiFi de casa
  • Presioná Guardar — el NodeMCU se reinicia y se conecta
  • El LED parpadea 3 veces cuando se conectó exitosamente
✓ Las credenciales quedan guardadas en memoria. La próxima vez que enciendas el NodeMCU se conecta solo automáticamente.
⚠️ Si cambiás de router o contraseña WiFi: mantené presionado el botón FLASH (D3) del NodeMCU durante 3 segundos al arrancar para borrar la config y volver a configurar.
05
CONECTAR AL JUEGO
Cada vez que jugás
  • Encendé el NodeMCU (conectado a cualquier cargador USB)
  • Esperá que parpadee 3 veces — está conectado al WiFi
  • Abrí el juego en cualquier dispositivo de la misma red WiFi
  • En el menú → Conectar Sensor → WiFi
  • El juego busca el NodeMCU automáticamente o ingresás la IP
💡 Para ver la IP del NodeMCU: conectá el USB a la PC, abrí el Monitor Serie del Arduino IDE a 115200 baudios y reiniciá. Va a mostrar algo como:

ws://192.168.1.XX:81 Esa es la dirección que ponés en el juego.
✓ Una vez conectado por WiFi podés jugar desde el celu, tablet, TV o PC — sin cables.
!
SOLUCIÓN DE PROBLEMAS
Casos frecuentes
No aparece la red BikeGame-Setup
El NodeMCU ya tiene WiFi guardado. Mantené presionado el botón FLASH (D3) 3 segundos al encender para resetear.
El sensor no detecta pedaleos
Revisá que OUT del sensor esté en D2. Ajustá el potenciómetro azul del sensor. Verificá que uses 3.3V y no 5V.
El juego no encuentra el NodeMCU por WiFi
Asegurate de estar en la misma red WiFi. Verificá la IP en el Monitor Serie. Revisá que el puerto 81 no esté bloqueado por el firewall.
Se desconecta seguido durante el juego
El NodeMCU puede estar lejos del router. Acercalo o usá un repetidor WiFi. También puede ser interferencia — probá cambiar el canal WiFi en el router.
Error al subir el código: "espcomm_upload_mem failed"
Mantené presionado el botón FLASH del NodeMCU mientras presionás Subir en el IDE. Soltalo cuando empiece la subida.
✓
CHECKLIST FINAL
Antes de jugar
  • Sensor HW-511 conectado en D2, VCC en 3.3V, GND en GND
  • Código subido al NodeMCU (nodemcu-sensor-hw511.ino)
  • WiFi configurado — NodeMCU se conecta solo al encender
  • NodeMCU encendido y LED parpadeó 3 veces
  • Dispositivo de juego en la misma red WiFi
  • Juego abierto → Conectar Sensor → WiFi → ¡A pedalear!
